场景筛选

统一运行设置

Agent：Claude Code 2.1.218、OpenCode 1.17.18

上游：真实 DeepSeek API

协议：Anthropic Messages / OpenAI Chat Completions

Harness 配置：每个 Agent 在全部场景中使用同一配置，不按任务裁剪工具。

Claude 实际 init：Bash、Edit、Read。

OpenCode 实际轨迹：read、glob、edit、write、bash，并可调用自己的 task 子 Agent。

环境隔离：禁用 WebFetch、仓库外目录和普通直连外网。这是测试环境边界，不规定任务行动路线。

凭据隔离：provider key 只进入 APG server 环境，不进入 Agent 进程。

Agent 可见的完整仓库

每个场景都复制同一份隔离仓库。场景卡中的文件只是与该任务直接相关的输入，并非权限白名单。
