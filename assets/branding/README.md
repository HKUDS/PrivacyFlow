# PrivacyFlow branding assets

The images in this directory are PrivacyFlow logo concepts created for this project.
The WebUI uses the vector mark at `src/gateway/webui/privacyflow-icon.svg`.
The older `apg-icon*.png` files remain as migration-era assets and are not used
by the current interface.

PrivacyFlow does not bundle Claude Code, OpenCode, Codex, or other Agent product logos.
Names of compatible products are used only to describe optional validation
targets and do not imply endorsement.

Bundled JavaScript library licenses are preserved under `docs/vendor/`.
